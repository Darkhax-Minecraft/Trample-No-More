<!-- description-start -->
This is the official GitHub repo for the TrampleNoMore mod. Adds several ways to avoid trampling crops. You can download this mod from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/trample-no-more) or [Modrinth](https://modrinth.com/mod/trample-no-more). Please report issues [here](https://github.com/Darkhax-Minecraft/Trample-No-More/issues).
<!-- description-end -->

## Maven Dependency
This project is available on the [BlameJared Maven](https://maven.blamejared.com).

If you are using [Gradle](https://gradle.org) you can add the mod as a dependency by adding the following
to your `build.gradle` file.

```groovy
repositories {
    maven {
        url 'https://maven.blamejared.com'
    }
}

dependencies {
     // NeoForge
     implementation group: 'net.darkhax.tramplenomore', name: 'tramplenomore-neoforge-26.1.2', version: '26.1.2.0'
     // Fabric
     implementation group: 'net.darkhax.tramplenomore', name: 'tramplenomore-fabric-26.1.2', version: '26.1.2.0'
     // Common / MultiLoader / Vanilla / No Loader
     implementation group: 'net.darkhax.tramplenomore', name: 'tramplenomore-common-26.1.2', version: '26.1.2.0'
}
```
